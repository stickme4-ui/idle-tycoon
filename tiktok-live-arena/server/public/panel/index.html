צריך להיות בלייב (ב-TikTok LIVE Studio) כדי להתחבר. אם הלייב עוד לא התחיל – המערכת תנסה שוב אוטומטית.

חיים

—

הפעלה ידנית

שגר אויבים או הפעל אפקט בלי מתנה – טוב לבדיקה או כדי לחמם את הלייב.

סימולטור אירועים

מדמה אירוע אמיתי מהלייב – עובר דרך כל החוקים, בדיוק כמו צופה אמיתי.

יומן אירועים

תומכים מובילים

מתנות ואירועים → פעולות

כל שורה = "כשקורה X → תעשה Y". הכמות מוכפלת במספר המתנות (5 ורדים = פי 5). שמות המתנות באנגלית בדיוק כמו בטיקטוק – אחרי ההתחברות ללייב תקבל רשימה אוטומטית. אפשר גם להשתמש במספר ה-ID של המתנה.

דמויות (מהחלש לחזק)

"מודל" = שם המודל במשחק. אפשר להשתמש בדמויות של GTA (עובד מיד) או בדמויות Add-On שהורדת מ-gta5-mods – פשוט כתוב כאן את שם המודל שלהן. "תמונה" היא לינק או נתיב לתמונה שתוצג ברצועת הדמויות באוברליי.

הוספה ל-TikTok LIVE Studio

  1. ב-LIVE Studio: לחץ Add source (הוסף מקור) ← בחר Game (או Screen) ובחר את GTA V.
  2. לחץ שוב Add source ← בחר Link (קישור).
  3. הדבק את הקישור של "הכל ביחד" מלמטה. גודל: 1080 × 1920.
  4. מתח את מקור הקישור על כל המסך ודאג שהוא מעל המשחק ברשימת המקורות.
  5. רוצה למקם כל רכיב בנפרד? הוסף כל קישור כמקור נפרד.

הרקע של האוברליי שקוף. אפשר להוסיף ?sound=0 לסוף הקישור כדי לכבות צלילים. מיקומים: ?hp=330&top=150&bottom=20

תצוגה מקדימה

השתמש בסימולטור בלוח הבקרה כדי לראות אפקטים כאן.

אפשרות 1 (מומלצת): שרת FiveM מקומי

שרת FiveM שרץ רק על המחשב שלך. אין סכנת באן, דמויות Add-On נטענות בלי OpenIV, ואין צורך ב-Script Hook. תיקיית השרת:

  1. התקן את FiveM (הלקוח) – צריך GTA V חוקי (Steam / Rockstar / Epic).
  2. הפעל START_FIVEM.bat (או START_ALL.bat שמפעיל גם את השרת הזה). בפעם הראשונה הוא יפתח:
    • דף הורדה של FXServer – מורידים את ה-build המומלץ האחרון ומחלצים לתיקייה fivem-server\artifacts
    • דף portal.cfx.re – יוצרים מפתח חינמי ומדביקים בחלון.
  3. פותחים FiveM ← לוחצים F8 ← כותבים connect 127.0.0.1:30120
  4. הנקודה למעלה תהפוך ל-"FiveM: מחובר". הדמות, הנשקים ונקודת ההתחלה מוגדרים ב-live_arena\config.lua.

אפשרות 2: מוד ל-GTA V רגיל (Story Mode)

הכנס את הנתיב של תיקיית GTA V (התיקייה שבה נמצא GTA5.exe). דוגמאות:
C:\Program Files (x86)\Steam\steamapps\common\Grand Theft Auto V
C:\Program Files\Rockstar Games\Grand Theft Auto V
C:\Program Files\Epic Games\GTAV

מה צריך להתקין במשחק (פעם אחת)

  1. Script Hook V – מ-dev-c.com/gtav/scripthookv. מעתיקים את ScriptHookV.dll ו-dinput8.dll לתיקיית המשחק.
  2. ScriptHookVDotNet – מ-GitHub releases. מעתיקים את כל הקבצים (ScriptHookVDotNet.asi, ScriptHookVDotNet2/3.dll) לתיקיית המשחק.
  3. להתקין .NET Framework 4.8 ו-Visual C++ Redistributable (בדרך כלל כבר מותקנים).
  4. ללחוץ "התקן / עדכן מוד" למעלה – זה מעתיק את TikTokArena.cs לתיקיית scripts ומחבר אותו לשרת הזה.
  5. להפעיל את GTA במצב Story Mode בלבד (לא אונליין!). כשהמוד מתחבר – הנקודה "GTA" למעלה תהפוך לירוקה.

⚠ מודים עובדים רק ב-Story Mode. אל תיכנס ל-GTA Online עם מודים מותקנים – זה עלול לגרום לחסימה. גרסת Enhanced של GTA V (2025) צריכה גרסאות Enhanced של Script Hook V – אם משהו לא עובד, השתמש בגרסת Legacy.

הוספת דמויות מ-gta5-mods (Add-On Peds)

  1. התקן OpenIV והפעל את "ASI Manager" ← התקן את OpenIV.ASI.
  2. צור תיקיית mods ב-OpenIV (Tools ← Options ← "mods" folder).
  3. בחר דמויות שמסומנות Add-On (לא Replace) ב-gta5-mods.com ← קטגוריית Player / Peds.
  4. לרוב יש בהן תיקיית DLC: מעתיקים ל-mods\update\x64\dlcpacks\ ומוסיפים שורה ל-dlclist.xml (ההוראות תמיד בקובץ readme של המוד).
  5. את שם המודל (כתוב ב-readme או בשם קובץ ה-.ydd/.yft) מכניסים בטאב "דמויות" במקום הדמות שאתה רוצה להחליף.
  6. אם המודל לא נטען – המוד ישתמש אוטומטית בחייל SWAT כדי שהלייב לא ייתקע.
