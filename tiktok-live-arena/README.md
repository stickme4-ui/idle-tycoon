# Live Arena – מערכת לייב אינטראקטיבית ל-TikTok + GTA V

לייקים, עוקבים ומתנות בלייב משגרים אויבים ב-GTA V. מד חיים, התראות ואפקטים מוצגים על המסך דרך TikTok LIVE Studio.

```
צופה בטיקטוק ──► שרת מקומי (המחשב שלך) ──► מוד ב-GTA V  (משגר אויבים, מדווח נזק)
                     │
                     └──► אוברליי ב-LIVE Studio  (מד חיים, התראות, אפקטים, רצועת דמויות)
```

## מה יש בפנים

| תיקייה | מה זה |
|---|---|
| `START.bat` | מפעיל את השרת (לחיצה כפולה) |
| `server/` | השרת המקומי + לוח הבקרה בעברית (כמו TikFinity) + האוברליי |
| `gta-mod/TikTokArena.cs` | המוד ל-GTA V (ScriptHookVDotNet v3) |

## התקנה – צעד אחר צעד

### 1. דרישות (פעם אחת)
1. **Node.js** (גרסת LTS) – <https://nodejs.org>
2. **GTA V** במחשב (Steam / Rockstar / Epic) – מצב **Story Mode** בלבד.
3. **Script Hook V** – <http://www.dev-c.com/gtav/scripthookv/> → להעתיק `ScriptHookV.dll` + `dinput8.dll` לתיקיית המשחק.
4. **ScriptHookVDotNet** (v3) – <https://github.com/scripthookvdotnet/scripthookvdotnet/releases> → להעתיק את כל הקבצים לתיקיית המשחק.
5. **TikTok LIVE Studio** עם הרשאת לייב.

### 2. הפעלת השרת
לחיצה כפולה על `START.bat`. בפעם הראשונה הוא מתקין את מה שצריך, ואז פותח את לוח הבקרה בדפדפן:
`http://127.0.0.1:7420/panel/`

> הפורט ברירת המחדל הוא 7420. אם הוא תפוס, השרת בוחר אוטומטית את הפורט הפנוי הבא, שומר אותו ומעדכן גם את המוד.

### 3. התקנת המוד
בלוח הבקרה ← טאב **"התקנת המוד"** ← מדביקים את הנתיב לתיקיית GTA V ← **"התקן / עדכן מוד"**.
הלוח בודק שהכל מותקן (Script Hook V, ScriptHookVDotNet) ומעתיק את המוד לתיקיית `scripts`.

(ידנית: להעתיק את `gta-mod/TikTokArena.cs` ואת `gta-mod/TikTokArena.ini` לתיקייה `GTA V\scripts\`.)

### 4. חיבור ל-LIVE Studio
1. **Add source → Game** ← GTA V.
2. **Add source → Link** ← `http://127.0.0.1:7420/overlay/all` (גודל 1080×1920), מעל המשחק.
3. מתחילים לייב ← בלוח הבקרה כותבים את שם המשתמש ← **התחבר**.

כשהכל מחובר, שתי הנקודות למעלה בלוח (טיקטוק + GTA) ירוקות.

## לוח הבקרה

- **לוח בקרה**: חיבור ללייב, מד חיים, סטטיסטיקות, יומן אירועים, תומכים מובילים, הפעלה ידנית וסימולטור מתנות (לבדיקה בלי לייב).
- **מתנות ואירועים**: כל חוק הוא "כשקורה X → תעשה Y" + אפקט.
  - טריגרים: מתנה (לפי שם או ID), כל N לייקים, עוקב חדש, שיתוף, פקודת צ'אט (למשל `!heal` עם זמן המתנה).
  - פעולות: שיגור אויבים, ריפוי, נזק, פצצה (השמדת כל האויבים), תקיפה אווירית, הילוך איטי, נשק לשחקן, הקפצה, ניקוי תור.
  - אפקטים על המסך: פיצוץ קונפטי, גל הדף, באנר בוס, ריפוי ירוק, פצצה, ברקים.
- **דמויות**: 9 רמות מהחלש לחזק (חיים, שריון, נשק, דיוק, מכפיל נזק, צבע, תמונה).
- **הגדרות**: חיים מקסימליים, מכפיל נזק, התחדשות, הסתרת HUD, מקסימום אויבים בו-זמנית, צלילים ועוד.

## איך מד החיים עובד
- בתוך המשחק הדמות שלך מוחזקת על כמות חיים קבועה. כל פגיעה מדווחת לשרת ונספרת מול "חיים וירטואליים" (ברירת מחדל 50,000), ולכן אפשר להחזיק לייב ארוך.
- אויבים חזקים פוגעים יותר (מכפיל נזק לכל דמות).
- כשהחיים מגיעים ל-0: הדמות מתה במשחק, האוברליי מציג K.O., ואחרי שהדמות קמה החיים מתמלאים.
- מתנות ריפוי מוסיפות חיים עם אנימציה ירוקה.
- ה-HUD של GTA (מפה, נשק, כסף) מוסתר לגמרי, כך שעל המסך נשאר רק האוברליי שלך.

## הוספת דמויות (גיבורי על וכו') מ-gta5-mods
הדמויות שמוגדרות כברירת מחדל הן דמויות מקוריות של GTA, ולכן עובדות מיד בלי הורדות. כדי לשים דמויות כמו בסרטון:

1. מתקינים **OpenIV** ← Tools ← ASI Manager ← מתקינים **OpenIV.ASI**, ויוצרים תיקיית `mods`.
2. ב-gta5-mods.com ← Player ← מחפשים דמויות **Add-On** (לא Replace).
3. מתקינים לפי ה-readme של כל מוד. בדרך כלל זה תיקיית DLC ל-`mods\update\x64\dlcpacks\` ושורה ב-`dlclist.xml`.
4. בטאב **דמויות** כותבים את **שם המודל** (מה-readme) בשדה "מודל" של הרמה שאתה רוצה.
5. אפשר לשים תמונה של הדמות (לינק) שתוצג ברצועת הדמויות באוברליי.

## פתרון בעיות
- **"The user is not LIVE right now"**: צריך להיות באמת בלייב. המערכת תנסה שוב לבד.
- **GTA לא מתחבר (נקודה אדומה)**: לבדוק בטאב ההתקנה שכל הסימונים ירוקים, ושהשרת רץ לפני או אחרי שהמשחק עלה (המוד מתחבר לבד). אפשר להסתכל ב-`ScriptHookVDotNet.log` בתיקיית המשחק.
- **Rate limit**: להירשם בחינם ב-eulerstream.com ולהדביק את המפתח בהגדרות.
- **יותר מדי אויבים / המשחק כבד**: להוריד את "מקסימום אויבים בו-זמנית" ל-15. השאר מחכים בתור.

> ⚠ מודים רק ב-Story Mode. אסור להיכנס ל-GTA Online עם מודים, זה מוביל לחסימה. החיבור לטיקטוק משתמש בספרייה לא רשמית (`tiktok-live-connector`) ועלול להפסיק לעבוד זמנית כשטיקטוק משנה דברים. אז מעדכנים את הספרייה.
