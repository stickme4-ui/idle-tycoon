# TradePilot: עוזר מסחר יומי מבוסס מחקר

תוכנה אחת שעושה את כל השלבים: סורקת את השוק, מוצאת הזדמנויות, Claude מנתח חדשות ובודק כל עסקה, מנהל הסיכונים מחשב גודל פוזיציה וחוסם חריגות, וההזמנה נשלחת לברוקר **בלחיצת כפתור אחת**. יש גם **מצב אוטומטי**.

> ⚠️ **זה לא ייעוץ השקעות.** מסחר יומי מסוכן, ורוב הסוחרים היומיים מפסידים כסף. התוכנה לא מבטיחה רווח.
> הסדר הנכון: דמו ← בדיקה היסטורית על נתונים אמיתיים ← 1-3 חודשי מסחר נייר ← רק אז סכום קטן בכסף אמיתי.

---

## התחלה מהירה (דמו, בלי שום חשבון)

1. התקן Python 3.11 או חדש יותר מ-https://www.python.org
2. בתיקייה `trading-bot`:
   ```bash
   python -m venv .venv
   # Windows:  .venv\Scripts\activate      Mac/Linux:  source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env        # ב-Windows: copy .env.example .env
   python run.py
   ```
3. פתח בדפדפן: **http://127.0.0.1:8000**

במצב דמו רץ שוק מדומה עם מניות בדויות ושעון מואץ (יום מסחר שלם בכמה דקות), כדי שתלמד את המערכת בלי סיכון.

## חיבור חשבון (Alpaca)

1. פתח חשבון ב-https://alpaca.markets. חשבון **Paper** (כסף וירטואלי) הוא חינמי.
   בדוק אם Alpaca פותחת חשבון אמיתי לתושבי ישראל. אם לא, אפשר להוסיף מתאם ל-Interactive Brokers.
2. ב-Dashboard של Alpaca צור מפתחות API **לחשבון ה-Paper**.
3. ערוך את `.env`:
   ```
   BROKER=alpaca
   ALPACA_API_KEY=...
   ALPACA_SECRET_KEY=...
   ALPACA_PAPER=true
   ```
4. (מומלץ) מפתח Claude מ-https://console.anthropic.com:
   ```
   ANTHROPIC_API_KEY=...
   ```
   בלי מפתח הבוט עובד, אבל בלי ניתוח Claude. החדשות מנותחות אז לפי מילות מפתח.
5. `python run.py`

המפתחות נשארים רק בקובץ `.env` במחשב שלך. הם לא נשלחים לדפדפן ולא נכתבים ללוג. השרת מאזין רק ל-`127.0.0.1`, כלומר רק המחשב שלך יכול להתחבר אליו.

**כסף אמיתי:** `ALPACA_PAPER=false`. הממשק יציג פס אדום, וכל ביצוע ידרוש אישור נוסף. מצב אוטומטי בכסף אמיתי **נעול** עד שתגדיר `ALLOW_LIVE_AUTO=true` ותקליד בממשק "אני מבין את הסיכון".

**נתונים:** התוכנית החינמית של Alpaca נותנת נתוני IEX, שהם רק חלק קטן מהנפח בשוק, ומגבילה את הסטרים ל-30 מניות. למסחר אמיתי מומלץ להגדיר `ALPACA_DATA_FEED=sip`, שדורש מנוי בתשלום.

| **פוזיציה פתוחה** | העסקה בפנים | אפשר לסגור ידנית בכל רגע. בכל מקרה הכול נסגר ב-15:55 |

- **מצב ידני:** שום דבר לא קורה בלי לחיצה שלך.

- **⚙ הגדרות:** אחוז סיכון לעסקה, הפסד יומי מקסימלי, מספר עסקאות ביום, שורט כן/לא, רשימת מעקב ועוד.

## על מה זה מבוסס

### אסטרטגיה 1: פריצת טווח הפתיחה ב-"Stocks in Play" (האסטרטגיה הראשית)
מבוססת על Zarattini, Barbon & Aziz (2024), *A Profitable Day Trading Strategy For The U.S. Equity Market*:
- **סינון:** מחיר מעל 5$, נפח ממוצע מעל מיליון מניות, ATR של 14 יום מעל 0.5$.
- **Stocks in Play:** נפח 5 הדקות הראשונות חייב להיות לפחות פי 1 מהממוצע של 14 הימים האחרונים. סוחרים רק ב-20 המניות עם הנפח היחסי הגבוה ביותר.
- **כיוון:** נר ראשון ירוק = קנייה בפריצה מעל הגבוה שלו. נר אדום = שורט בשבירה מתחת לנמוך שלו (כבוי כברירת מחדל).
- **סטופ:** 10% מה-ATR. אין יעד רווח: יוצאים בסוף היום.
- במאמר דווחו Sharpe של 2.81 ותשואה של יותר מ-1,600% בשנים 2016-2023, ו-QuantConnect שחזרו את התוצאה עם Sharpe בסביבות 2.4. **אבל:** זו בדיקה היסטורית, הכותבים מוכרים שירותי מסחר, ואין עדות למסחר אמיתי. לכן חובה לבדוק בעצמך (ראה "בדיקה היסטורית" למטה).

### אסטרטגיה 2: מומנטום חדשות (ניסיונית, ידנית בלבד)
מבוססת על Lopez-Lira & Tang, *Can ChatGPT Forecast Stock Price Movements?* (גרסה מעודכנת, 2025). מודלי שפה גדולים מזהים טוב את כיוון התגובה לכותרת, וחלק מהתנועה ממשיך. מצד שני, היתרון מתכווץ ככל שיותר אנשים משתמשים במודלים כאלה, והוא חזק בעיקר במניות קטנות. לכן הבוט דורש שלושה תנאים: כותרת מהותית לפי Claude, מחיר מעל VWAP (בקנייה), ונפח יחסי גבוה.

### Claude
- מנתח כל כותרת: כיוון, עד כמה היא מהותית, סוג האירוע וסיכום בעברית.
- בודק כל הצעה: "מתאים", "בזהירות" או "לדלג", עם נימוקים וסיכונים בעברית. במצב אוטומטי, "לדלג" חוסם את העסקה.
- **Claude לא קובע מחירים, כמויות או סטופים.** את אלה קובעים חוקים קבועים ומנהל הסיכונים. מודל: `claude-opus-5-5`, אפשר לשנות ב-`AI_MODEL`.

### ניהול סיכונים (חל בכל מצב, על כל הזמנה)
- גודל פוזיציה לפי סיכון: הפסד בסטופ של עד 0.5% מההון ועד 100$ לעסקה.
- הפסד יומי מקסימלי של 2% או 300$, **כולל הסיכון בפוזיציות הפתוחות**. אחרי שמגיעים אליו, אין כניסות עד מחר.
- מפסק זרם אחרי 3 הפסדים ברצף, ומקסימום 6 עסקאות ו-4 פוזיציות במקביל.
- פוזיציה בודדת עד 25% מההון, בלי מרג'ין.
- **לא רודפים אחרי מחיר:** אם המחיר כבר ברח יותר מחצי R מנקודת הכניסה, העסקה נחסמת.
- הסטופ נשלח לברוקר יחד עם הכניסה (bracket/OTO), ולכן הוא שומר עליך גם אם המחשב נכבה.
- בלי כניסות לפני 9:35 ואחרי 15:30. כל הפוזיציות נסגרות ב-15:55.

## בדיקה היסטורית (Backtest)

```bash
# על נתונים אמיתיים (דורש מפתחות Alpaca ב-.env):
python -m tradepilot.backtest --source alpaca --start 2025-06-01 --end 2026-10-31 --symbols-file universe.txt
# הדגמה על נתונים מדומים:
python -m tradepilot.backtest --source demo --days 120
```

הבדיקה משתמשת בדיוק באותו קוד איתות כמו הבוט החי. היא כוללת עמלה של 0.0035$ למניה ו-slippage, ובמקרה ספק (כניסה וסטופ באותו נר) היא מניחה את התרחיש הגרוע. בנוסף היא מריצה סימולציית Monte Carlo לטווח התוצאות האפשרי ומשווה את חצי התקופה הראשון לשני כדי לבדוק אם היתרון יציב.

**הערה:** בנתוני הדמו האסטרטגיה מפסידה, וזה בכוונה. השוק המדומה הוא אקראי, ואסטרטגיה אמורה להפסיד בשוק אקראי כשמשלמים עמלות. זה מראה שהבדיקה עצמה הוגנת. רק בדיקה על נתונים אמיתיים, עם רשימת מניות רחבה (100 ומעלה), אומרת משהו על האסטרטגיה.

על מה להסתכל: לפחות 200 עסקאות, profit factor מעל 1.2 **אחרי עלויות**, תוצאות דומות בשני חצאי התקופה, ושה-drawdown בתרחיש הגרוע של Monte Carlo (p95) הוא משהו שאתה מוכן לספוג.

## מה שופר לעומת day-trader-skill

| | day-trader-skill | TradePilot |
|---|---|---|
| אסטרטגיה | ORB רגיל ו-RSI מספר לימוד | ORB **מוגבל ל-Stocks in Play** לפי מחקר, עם דירוג לפי נפח יחסי |
| נתונים | Yahoo (לא רשמי), נרות של 1-5 דקות | API רשמי של Alpaca, websocket של עסקאות ונרות בזמן אמת, חדשות בזמן אמת |
| "מכונת זמן" | דגימה אקראית של נרות, שמוחקת מומנטום | backtest על היסטוריה אמיתית עם עלויות, ו-Monte Carlo על ימי מסחר |
| ביצוע | 3 שלבים ידניים בצ'אט | כפתור אחד, "אישור מראש" לטריגר, ומצב אוטומטי |
| חדשות | כותרות בלבד | Claude מסווג כל כותרת (כיוון ומהותיות) ובודק כל עסקה |
| סיכונים | בדיקה לפני הזמנה | אותן בדיקות, ובנוסף הפסד יומי שכולל סיכון פתוח, מפסק זרם, מניעת רדיפה בזמן הביצוע, מתג חירום וסטופ אצל הברוקר |

## מבנה הקוד

```
run.py                     הפעלה
tradepilot/
  engine.py                המנוע: נתונים -> אסטרטגיות -> הצעות -> Claude -> סיכונים -> הזמנות
  strategies/orb.py        פריצת טווח פתיחה ב-Stocks in Play
  strategies/news_momentum.py
  risk.py                  גודל פוזיציה ובדיקות קשיחות
  ai.py                    Claude: ניתוח חדשות ובדיקת עסקאות (structured outputs)
  scoring.py               ציון 0-100 שקוף, עם פירוט לכל נקודה
  broker/alpaca.py         Alpaca (נייר / אמיתי)
  broker/sim.py            ברוקר מדומה (דמו, בדיקות, backtest)
  data/alpaca_feed.py      נתוני עבר, websocket נרות/עסקאות/חדשות
  data/sim.py              שוק מדומה לדמו
  backtest.py              בדיקה היסטורית
  server.py + web/         הממשק (עברית, מתעדכן בזמן אמת)
tests/                     בדיקות (pytest)
```

בדיקות: `python -m pytest -q`

## מגבלות ידועות
- החיבור ל-Alpaca נכתב לפי ה-SDK הרשמי (alpaca-py 0.45), אבל **לא נבדק מול חשבון אמיתי** בסביבת הפיתוח. בהפעלה הראשונה בחשבון Paper צריך לוודא שהזמנה, סטופ וסגירה עובדים כמצופה.
- הכניסה היא הזמנת שוק ברגע הטריגר, ולכן ייתכן slippage. בדיקת "לא רודפים" מגבילה אותו.
- שורט דורש חשבון מרג'ין, וייתכנו עלויות השאלה שהבוט לא מחשב.
- מיסים: רווחי מסחר יומי חייבים במס. התייעץ עם רואה חשבון.
